# kvctlTool 需求文档

## 1. 项目概述

**项目名称**：kvctlTool  
**项目类型**：跨平台桌面应用程序  
**开发语言**：TypeScript / Rust（视最终选型）  
**界面框架**：Web 技术栈（HTML5 + CSS3）  
**功能定位**：`craftctl` 命令行工具的现代化图形化客户端，支持**本地直连**与**SSH 远程执行**双模式，用于对后端分布式服务执行 KV 操作、集群管理及自定义命令。

> **版本说明**：本文档基于 V1.0（Qt C++ 版）功能进行跨平台重构，核心目标为解决平台依赖问题、引入 SSH 远程执行能力，并全面提升界面美观度与交互体验。

---

## 2. 技术栈选型

| 层级 | 技术方案 | 选型理由 |
|-----|---------|---------|
| 应用框架 | **Electron 28+** (Chromium + Node.js) | 成熟稳定、跨平台支持好、生态丰富、开发者众多 |
| 前端框架 | **Vue 3 + TypeScript + Vite** | 响应式系统成熟、组合式 API、类型安全、开发体验好 |
| UI 组件库 | **Element Plus** | 设计现代、暗色主题支持好、组件丰富、文档完善 |
| 状态管理 | **Pinia** | 轻量、TypeScript 友好、Devtools 支持 |
| 本地存储 | **electron-store** + **better-sqlite3** + **keytar** | 配置持久化、SQL结构化数据、安全凭据存储 |
| SSH 客户端 | **Node.js `ssh2` 库**（主进程中调用） | 成熟稳定、跨平台支持、文档完善 |
| 进程管理 | **Node.js child_process / Electron IPC** | 安全地调用本地 `craftctl` 进程 |

> **备选方案**：若追求更小的包体积，可将 Electron 替换为 Tauri v2。

## 4. 非功能需求

### 4.1 跨平台兼容性
- **Windows**：Windows 10 及以上，支持 WebView2 运行时。
- **macOS**：macOS 11 (Big Sur) 及以上，支持 WebKit。
- **Linux**：主流发行版（Ubuntu 20.04+ / CentOS 8+ / Arch），需 WebKitGTK。

### 4.2 性能需求
- 应用冷启动时间 < 2s（在 SSD 设备上）。
- 界面交互响应延迟 < 100ms。
- SSH 连接建立时间 < 5s（正常网络条件下）。
- 大输出（>10MB）渲染时不阻塞 UI，采用虚拟滚动或分页加载。

### 4.3 安全需求
- 所有 SSH 认证凭据必须存储于系统密钥链，禁止明文落盘。
- 私钥文件读取后仅在内存中使用，不额外复制到临时目录。
- 命令执行结果中的敏感信息（如 token）支持一键脱敏（远期扩展）。

### 4.4 可靠性需求
- 命令执行需设置超时机制（默认 30s，SSH 模式可配置）。
- 应用崩溃恢复：记录未完成的操作日志，重启后可查看。
- 配置数据定期备份：SQLite 数据库损坏时可恢复。

### 4.5 可扩展性需求
- 架构预留多语言支持（i18n）。
- 架构预留插件机制，未来可扩展支持其他命令行工具（不仅限于 `craftctl`）。

## 6. 数据模型

### 6.1 SSH 配置 (SSHConfig)

```typescript
interface SSHConfig {
  id: string;              // UUID
  name: string;            // 显示名称，如 "生产-Node1"
  host: string;            // 主机地址
  port: number;            // 端口，默认 22
  username: string;        // 用户名
  authType: 'password' | 'privateKey'; // 认证方式

  // privateKeyPath?: string;
  // passphrase?: string;

  updatedAt: number;

```

interface ServiceAddress {

## 6.5 数据存储方案

### 6.5.1 存储层级划分

| 数据类型 | 存储位置 | 存储方案 |
|---------|---------|---------|
| 应用配置（theme、defaultMode 等） | electron-store | 轻量 key-value，自动持久化 |
| SSH 配置（非敏感字段） | SQLite | 结构化数据，需增删改查 |
| 服务地址历史 | SQLite | 结构化数据，需排序、去重 |
| 命令历史 | SQLite | 结构化数据，需分页查询 |
| SSH 密码 / 私钥 passphrase | 系统密钥链 | keytar 跨平台调用 |

### 6.5.2 SQLite 数据库表设计

```sql
-- SSH 配置表
CREATE TABLE ssh_configs (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  host TEXT NOT NULL,
  port INTEGER DEFAULT 22,
  username TEXT NOT NULL,
  auth_type TEXT NOT NULL CHECK(auth_type IN ('password', 'privateKey')),
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);

-- 服务地址历史表
CREATE TABLE service_addresses (
  id TEXT PRIMARY KEY,
  protocol TEXT NOT NULL CHECK(protocol IN ('tcp', 'udp', 'http')),
  host TEXT NOT NULL,
  port INTEGER NOT NULL,
  last_used_at INTEGER NOT NULL,
  use_count INTEGER DEFAULT 1,
  UNIQUE(protocol, host, port)
);

-- 命令历史表
CREATE TABLE command_history (
  id TEXT PRIMARY KEY,
  type TEXT NOT NULL CHECK(type IN ('preset', 'custom')),
  command TEXT NOT NULL,
  args TEXT NOT NULL,  -- JSON 数组
  mode TEXT NOT NULL CHECK(mode IN ('local', 'ssh')),
  ssh_config_id TEXT,
  executed_at INTEGER NOT NULL,
  duration INTEGER,
  status TEXT NOT NULL CHECK(status IN ('success', 'error')),
  FOREIGN KEY(ssh_config_id) REFERENCES ssh_configs(id)
);
```

> **安全注意**：密码和私钥 passphrase 绝不存入 SQLite，必须通过 keytar 存储到系统密钥链。

### 7.2 关键交互细节

1. **模式切换动画**：切换本地/SSH 模式时，左侧配置区平滑过渡，SSH 模式下显示 SSH 配置卡片。
2. **命令执行 Loading**：按钮变为 Spin 状态，输出区顶部显示进度条。

## 8. 异常处理

| 场景 | 处理方式 |
|-----|---------|
| 本地未找到 `craftctl` | Toast 警告 + 自动建议切换 SSH 模式 |
| SSH 连接超时 | Toast 错误 + 显示重试按钮 |
| SSH 认证失败 | Modal 弹窗提示，引导检查密码/密钥 |
| 远程服务器无 `craftctl` | Toast 警告 + 引导在远程服务器安装 |
| Key/Value 为空时执行 Put | Input 框红色抖动 + 底部提示文字 |
| Key 为空时执行 Delete | 同上 |
| 自定义命令为空时执行 | 同上 |
| 命令执行返回非零退出码 | 输出区红色高亮错误信息，不阻塞后续操作 |
| 网络中断导致 SSH 断开 | 顶部 Banner 提示 + 一键重连 |
| 端口输入非数字或越界 | Input 框实时拦截，禁止输入非法字符 |
| SSH 模式下未连接点击「浏览」 | Alert 弹窗提示：请先建立 SSH 连接 |
| SFTP 读取远程目录失败 | 远程文件浏览器内显示错误信息 |
| SSH 模式下未连接执行命令 | Toast 错误提示：当前未建立 SSH 连接，请先连接服务器后再执行命令 |
| 远程文件浏览器无法回退到 `/` 目录 | 顶层目录固定为 `/`，支持从家目录回退到 `/` |
