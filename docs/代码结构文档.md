## 3. 核心文件说明

### 3.1 Electron 主进程 (`electron/main.ts`)

**功能**: 
- 窗口管理
- IPC 通信处理
- craftctl 命令执行
- SSH 连接与远程执行
- 数据持久化

**关键 IPC 处理器**:
| 处理器 | 功能 |
|--------|------|
| `store:get/set` | 配置读写 (electron-store) |
| `dialog:openFile` | 打开文件对话框选择命令行工具 |
| `craftctl:check` | 检测本地命令行工具是否可用 |
| `craftctl:execute` | 执行 craftctl 命令 (本地模式) |
| `ssh:connect` | 建立 SSH 连接 |
| `ssh:execute` | 远程执行命令 |
| `ssh:disconnect` | 断开 SSH 连接 |
| `db:getSSHConfigs/saveSSHConfig/deleteSSHConfig` | SSH 配置管理 |
| `db:getServiceAddresses/saveServiceAddress` | 服务地址历史 |

### 3.2 预加载脚本 (`electron/preload.ts`)

**功能**: 暴露安全 API 给渲染进程

**暴露的 API**:
```typescript
window.api = {
  store: { get, set },
  dialog: { openFile },
  craftctl: { check, execute },
  ssh: { connect, execute, disconnect },
  db: { getSSHConfigs, saveSSHConfig, deleteSSHConfig, getServiceAddresses, saveServiceAddress }
}
```

### 3.3 状态管理 Stores

#### connection.ts
- `protocol`: 'tcp' | 'udp'
- `host`: string (默认 '127.0.0.1')
- `port`: number (默认 7375)
- `mode`: 'local' | 'ssh'
- `toolPath`: string (命令行工具路径)
- `history`: 服务地址历史记录

#### ssh.ts
- `configs`: SSH 配置列表
- `selectedConfigId`: 当前选中的配置 ID
- `connectionStatus`: 连接状态映射
- `isConnected`: 是否已连接
- `loadConfigs`, `saveConfig`, `deleteConfig`, `selectConfig`, `disconnect`

#### output.ts
- `outputs`: 命��输出列表
- `toasts`: 通知列表
- `addOutput`, `clear`, `addToast`

#### settings.ts
- `theme`: 'dark' | 'light'
- `prefixQuery`: 前缀查询开关
- `keysOnly`: 仅查询 Key 开关
- `preserveOutput`: 保留输出历史开关
- `outputFontSize`: 输出区字体大小
- `uiFontSize`: 软件界面字体大小
- `loadSettings`, `saveSettings`, `toggleTheme`, `applyTheme`, `applyElementPlusTheme`

## 5. 数据流

```
用户操作 (Vue)
    │
    ▼
组件 emit / Pinia action
    │
    ▼
window.api.* (preload.ts)
    │
    ▼
ipcRenderer.invoke (Electron IPC)
    │
    ▼
主进程处理 (main.ts)
    │
    ├──► child_process.spawn (本地 craftctl)
    │
    ├──► ssh2 client (SSH 远程执行)
    │
    └──► electron-store (数据持久化)
    │
    ▼
结果通过 IPC 回调返回
    │
    ▼
Vue 组件更新显示
```

## 7. 常用操作

### 本地模式执行命令
```typescript
await window.api.craftctl.execute({
  command: 'get mykey',
  mode: 'local',
  endpoint: 'tcp://127.0.0.1:7375',
  options: { prefix: false, keys: false }
})
```

### SSH 远程执行
```typescript
// 1. 连接
await window.api.ssh.connect({
  host: '192.168.1.1',
  port: 22,
  username: 'root',
  authType: 'password',
  password: 'xxx'
})

// 2. 执行
await window.api.ssh.execute('craftctl -e tcp://127.0.0.1:7375 get mykey')

// 3. 断开
await window.api.ssh.disconnect()
```
