## 3. 核心文件说明

### 3.1 Electron 主进程 (`electron/main.ts`)

**功能**: 
- 窗口管理
- IPC 通信处理
- craftctl 命令执行
- SSH 连接与远程执行
- 数据持久化

**关键 IPC 处理器**:
| 处理器 | 功能 |
|--------|------|
| `store:get/set` | 配置读写 (electron-store) |
| `dialog:openFile` | 打开系统文件对话框选择命令行工具（本地模式） |
| `dialog:openFileRemote` | 通过 SFTP 读取远程服务器目录列表（SSH 模式） |
| `craftctl:check` | 检测本地命令行工具是否可用 |
| `craftctl:execute` | 执行 craftctl 命令 (本地模式) |
| `ssh:connect` | 建立 SSH 连接 |
| `ssh:testConnect` | 测试 SSH 连接 |
| `ssh:execute` | 远程执行命令 |
| `ssh:disconnect` | 断开 SSH 连接 |
| `ssh:checkConnection` | 检测当前是否存在活跃的 SSH 连接 |
| `db:getSSHConfigs/saveSSHConfig/deleteSSHConfig` | SSH 配置管理 |
| `db:getServiceAddresses/saveServiceAddress` | 服务地址历史 |

### 3.2 预加载脚本 (`electron/preload.ts`)

**功能**: 暴露安全 API 给渲染进程

**暴露的 API**:
```typescript
window.api = {
  store: { get, set },
  dialog: { openFile, openFileRemote },
  craftctl: { check, execute },
  ssh: { connect, testConnect, execute, disconnect, checkConnection },
  db: { getSSHConfigs, saveSSHConfig, deleteSSHConfig, getServiceAddresses, saveServiceAddress }
}
```

### 3.3 状态管理 Stores

#### connection.ts
- `protocol`: 'tcp' | 'udp' | 'http'
- `host`: string (默认 '127.0.0.1')
- `port`: number (默认 7375)
- `mode`: 'local' | 'ssh'
- `toolPath`: string (命令行工具路径)
- `history`: 服务地址历史记录
- `endpoint`: 计算属性，格式 `protocol://host:port`
- `endpointFlag`: 计算属性，`http` 协议返回 `--endpoints=...`，其他返回 `-e ...`

#### ssh.ts
- `configs`: SSH 配置列表
- `selectedConfigId`: 当前选中的配置 ID
- `connectionStatus`: 连接状态映射
- `isConnected`: 是否已连接
- `loadConfigs`, `saveConfig`, `deleteConfig`, `selectConfig`, `disconnect`, `getStatusClass`

#### SettingsDialog.vue 组件功能
- 接收 `executeMode` prop，用于实时判断当前执行模式
- 「浏览」按钮根据 `executeMode` 切换行为：SSH 模式下通过 SFTP 浏览远程文件，本地模式调用系统文件对话框
- 可配置命令行工具路径、字体大小、主题

#### SSHManager.vue 组件功能
- 新增/编辑/删除 SSH 配置
- 支持密码认证和私钥认证
- 连接状态实时显示 (绿色=已连接, 灰色=未连接, 红色=错误)
- 连接/断开按钮，带加载动画
- 测试连接功能

#### RemoteFileBrowserDialog.vue 组件功能
- SSH 模式下设置界面「浏览」按钮触发的远程文件选择弹窗
- 通过 `window.api.dialog.openFileRemote(dir)` 调用主进程 SFTP 读取远程目录
- 支持目录层级导航（点击进入子目录、返回上级目录，顶层可到达 `/`）
- 区分文件与文件夹图标标识
- 选中文件后回传完整远程路径到 SettingsDialog

#### output.ts
- `outputs`: 命令输出列表
- `toasts`: 通知列表
- `addOutput`, `clear`, `addToast`

#### settings.ts
- `theme`: 'dark' | 'light'
- `prefixQuery`: 前缀查询开关
- `keysOnly`: 仅查询 Key 开关
- `preserveOutput`: 保留输出历史开关
- `outputFontSize`: 输出区字体大小
- `uiFontSize`: 软件界面字体大小
- `loadSettings`, `saveSettings`, `toggleTheme`, `applyTheme`, `applyElementPlusTheme`

## 5. 数据流

```
用户操作 (Vue)
    │
    ▼
组件 emit / Pinia action
    │
    ▼
window.api.* (preload.ts)
    │
    ▼
ipcRenderer.invoke (Electron IPC)
    │
    ▼
主进程处理 (main.ts)
    │
    ├──► child_process.spawn (本地 craftctl)
    │
    ├──► ssh2 client (SSH 远程执行)
    │
    └──► electron-store (数据持久化)
    │
    ▼
结果通过 IPC 回调返回
    │
    ▼
Vue 组件更新显示
```

## 7. 常用操作

### 本地模式执行命令
```typescript
await window.api.craftctl.execute({
  command: 'get mykey',
  mode: 'local',
  endpoint: 'tcp://127.0.0.1:7375',
  options: { prefix: false, keys: false }
})
```

### SSH 远程执行
```typescript
// 1. 连接
await window.api.ssh.connect({
  host: '192.168.1.1',
  port: 22,
  username: 'root',
  authType: 'password',
  password: 'xxx'
})

// 2. 执行（使用用户配置的 toolPath）
const toolPath = '/usr/local/bin/craftctl'  // 来自 connectionStore.toolPath
await window.api.ssh.execute(`${toolPath} -e tcp://127.0.0.1:7375 get mykey`)
// http 协议时：${toolPath} --endpoints=http://127.0.0.1:7375 get mykey

// 3. 断开
await window.api.ssh.disconnect()
```

## 8. 已完成功能 & 待实现功能 / 已知问题

### 已完成功能
- ✅ 启动时默认选中本地模式（若本地未检测到 `craftctl` 则自动切换 SSH 模式）
- ✅ `http` 协议支持，命令参数自动切换为 `--endpoints=` 格式
- ✅ SSH 远程文件浏览，支持回退至 `/` 顶层目录
- ✅ SSH 模式下 KV 操作和自定义命令共用统一的远程执行逻辑
- ✅ SSH 未连接时执行命令拦截，Toast 提示用户先建立连接
- ✅ 命令输出回显使用用户配置的 `toolPath`，不再硬编码 `craftctl`
- ✅ 隐藏 Electron 默认菜单栏（`autoHideMenuBar: true`）
- ✅ 本地模式下协议/端口/主机地址自动持久化保存
- ✅ SSH 远程模式下协议/端口/主机地址与 SSH 服务器配置关联存储（切换服务器自动加载对应连接配置）

### 待实现 / 已知问题
1. 🔴 SSH 密码/私钥 passphrase 安全存储 (当前用 electron-store，明文存储)
2. 🟡 命令执行超时处理
3. 🟡 大输出渲染性能 (虚拟滚动)
4. 🟡 自动重连
5. 🟡 快捷键全局注册
6. 🟡 启动画面
7. 🟡 多语言支持 (i18n)
